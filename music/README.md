# music/

Carica qui le tue canzoni e i tuoi stem (`.wav`, `.mp3`, `.m4a`, `.ogg`, `.flac`).

- Puoi buttare i file direttamente qui, o creare una sottocartella per ogni brano
  (es. `music/moby-extreme-ways/drums.wav`).
- L'app li legge automaticamente da GitHub: apri il sito, tab "Catalogo GitHub",
  e il mix si crea da solo (mescolato a caso a ogni sessione).
- Consiglio: converti i WAV in `.m4a` o `.mp3` — si caricano molto più in fretta.
